# Task Board

A Jira-style task board application built with vanilla HTML, CSS, and JavaScript.

## Features

- 📋 Create and manage tasks
- ✅ Mark tasks as done
- 🎯 Priority levels (High, Medium, Low)
- 🖱️ Drag and drop tasks between columns
- 💾 Local storage persistence
- 📊 Task statistics display

## How to Use

1. Open `index.html` in your browser
2. Enter a task description in the input field
3. Select priority level
4. Click "Create Task" or press Enter
5. Drag tasks between "To Do" and "Done" columns
6. Tasks are automatically saved to your browser's local storage

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)
- Local Storage API

## Installation

Simply clone the repository and open `index.html` in your web browser. No build process or dependencies required!

```bash
git clone https://github.com/yourusername/task-board.git
cd task-board
open index.html
```
